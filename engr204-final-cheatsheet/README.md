# ENGR& 204 — Electrical Circuits: Ultimate Final Exam Cheat Sheet

This folder is a **self-contained** workspace for building the ultimate cheat sheet for the
ENGR& 204 (Electrical Circuits) final exam at Green River College. It has **nothing to do**
with the rest of this repository — it just lives here so you have a GitHub place to drop files.

## What's here

| File | What it is |
|---|---|
| `CHEAT_SHEET.md` | The master cheat sheet — every formula, method, and step-by-step approach you need. Open it on a screen or print it. |
| `WORKED_EXAMPLES.md` | Fully solved example problems for each problem type (the "show your work" version). |
| `QUICK_REFERENCE.md` | One-page condensed formula card for last-second review. |
| `source-files/` | **Put your own files here** — past exams, sample exams, homework, lecture notes, solutions. |

## How to USE the cheat sheet during studying

- Read `CHEAT_SHEET.md` top to bottom once — it's organized in the order the quarter is taught,
  with the **end-of-quarter RC / RL / RLC transient material expanded the most** (that's where
  the final puts the most weight).
- Drill the matching problems in `WORKED_EXAMPLES.md`.
- The night before, only review `QUICK_REFERENCE.md`.

## Printing

GitHub renders the Markdown nicely. To make a paper copy: open the `.md` file on GitHub,
use your browser's **Print → Save as PDF**, or paste into any Markdown editor (Typora, VS Code
preview, Obsidian) and export. The LaTeX-style math (`$...$`) renders in most of these.
