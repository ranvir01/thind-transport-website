## How to upload (no git knowledge needed)
1. Open this folder on GitHub (URL is in the chat).
2. Click **Add file → Upload files**.
3. Drag in all your files (you can drop many at once).
4. Scroll down, click **Commit changes** (commit directly to this branch).
5. Tell me in chat "files are uploaded" and I'll process them.
