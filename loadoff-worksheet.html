LoadOff — Human Worksheet

Everything that needs a human — real credentials, account signups, photos, decisions. Nothing here blocks the app: every integration ships with a simulated or manual fallback, and the /hub/demo simulation fabricates the rest. Do these to make the fabricated parts real. Last updated 2026-08-09.

1 · Credentials to add in Vercel → Project → Environment Variables (Production)

Live maps & geocoding needs key

Unlocks real map tiles on load tracking, driver ETA, and the shareable tracking link. Today routing falls back to public OSRM and addresses geocode through the fallback geocoder.

Get it: account.mapbox.com → free tier is fine to start · Set: NEXT_PUBLIC_MAPBOX_TOKEN (public, pk.*) and MAPBOX_TOKEN (secret, sk.*)

Outbound email (invoices, driver statements, dunning) needs creds

Invoice PDFs, settlement statements, and payment reminders are generated today but only emailed when SMTP is configured. Any provider with SMTP works (Google Workspace, Fastmail, SES SMTP).

Set: SMTP_HOST SMTP_PORT SMTP_USER SMTP_PASS SMTP_FROM — use a subdomain sender like billing@mail.thindtransport.com and add its SPF/DKIM DNS records at your registrar

Push notifications (driver app + office) needs keys

Web push for load assignments, message alerts, and dispatch nudges. Generate a VAPID pair once — one command, no account needed.

Get it: npx web-push generate-vapid-keys · Set: VAPID_PUBLIC_KEY VAPID_PRIVATE_KEY VAPID_CONTACT (mailto:you@…)

AI rate-con parser (paste / PDF intake) needs key

The paste-intake box and PDF import use Claude to turn rate confirmations into structured loads. Without the key it falls back to the regex parser (works, less magic).

Get it: console.anthropic.com → API keys · Set: ANTHROPIC_API_KEY (optionally ANTHROPIC_MODEL)

FMCSA carrier vetting needs key

Live SAFER lookups when vetting brokers/carriers (authority, insurance, safety rating). Free government key, instant issue.

Get it: mobile.fmcsa.dot.gov/QCDevsite → register → WebKey · Set: FMCSA_WEBKEY

Diesel price feed optional

Weekly EIA on-highway diesel average powering the fuel widgets; a static fallback table ships in the repo.

Get it: eia.gov/opendata (free) · Set: EIA_API_KEY

File uploads (POD photos, documents) verify

Vercel Blob token — normally auto-provisioned when Blob storage is attached to the project. Verify it exists in Production; PODs won't persist without it.

Set: BLOB_READ_WRITE_TOKEN (Vercel → Storage → Blob)

2 · Partner accounts (each is simulated until you sign up)

QuickBooks Online simulated

"Push to QBO" currently records the sync locally. Real sync needs an Intuit developer app (OAuth client), then connect from Settings → Integrations.

Fuel cards — WEX / EFS / Comdata / AtoB simulated

Fuel transaction import runs on demo feeds. Each provider issues API/feed credentials to the fleet account holder; request "transaction file/API access" from your rep.

Load boards — DAT / Truckstop simulated

Board search results are fabricated for the demo. Both require a paid subscription plus an API addendum.

ELD / telematics — TruckerCloud, Samsara et al. simulated

HOS clocks and truck GPS in the office views are demo data until an ELD aggregator account is connected.

Factoring partner simulated

"Submit to factor" produces the packet and records submission; electronic submission needs your factor's API credentials (ask your account manager).

Tolls — Bestpass / PrePass · Banking — Plaid · MVR — SambaSafety later

Stubs exist behind Settings → Integrations. Sign up only when the workflow matters to you.

3 · Real content only you can provide

  • Photos: real truck/driver/yard photos for the marketing site and driver profiles (current ones are placeholders/stock).
  • Tenant branding: logo + brand accent hex for each carrier tenant (Settings → Appearance applies it to the identity chip, portal, and PDFs).
  • Company facts: MC/DOT numbers, insurance certs, W-9 — used on invoice PDFs and broker packets. Verify what's seeded is current.
  • Driver invitation code: rotate DRIVER_INVITATION_CODE before onboarding real drivers.
